# Public Sentiment Analysis on Sumatra Flood Disasters (SVM)

An NLP-driven Machine Learning web application designed to analyze and classify public social media sentiment regarding flood disaster events in Sumatra, Indonesia, using the Support Vector Machine (SVM) algorithm.

## 🚀 Live Demo
- **URL:** https://sumatra-flood-sentiment-svm.vercel.app

## ✨ Key Features
- **Text Preprocessing Pipeline:** Automated text cleaning, case folding, tokenization, stopword removal, and stemming.
- **Feature Extraction:** Term Frequency-Inverse Document Frequency (TF-IDF) text vectorization.
- **SVM Sentiment Classifier:** Classifies public reaction into positive, negative, and neutral categories with optimal hyperplanes.
- **Disaster Response Analytics:** Interactive visual dashboards with sentiment trends, word clouds, and model accuracy metrics.

## 🛠️ Tech Stack
- **Frontend / Web:** React, TypeScript, Tailwind CSS
- **Machine Learning & NLP:** Support Vector Machine (SVM), TF-IDF Vectorizer
- **Deployment:** Vercel & GitHub
